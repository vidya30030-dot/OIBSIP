# Task 1: GreenNest - Indoor Plant Store Landing Page
This is a responsive, modern landing page built as part of the **Oasis Infobyte Web Development & Designing Internship (Level 1 - Task 1)**.
## 🛠️ Features
- **Navigation:** Fixed header with smooth-scrolling anchors.
- **Hero Banner:** Eye-catching background image with Call-To-Action (CTA).
- **About / Features:** 3-column card design showing core benefits using CSS Flexbox.
- **Featured Products:** Product display cards with clean typography and images.
- **Responsive:** Fluid layout using modern CSS media queries.
## 💻 Tech Stack
- HTML5
- CSS3 (Flexbox & CSS Variables)
- Google Fonts (Poppins)
