# 🌿 GreenNest — Indoor Plant Store Landing Page

---

## 📌 Project Overview

**GreenNest** is a visually appealing, responsive landing page designed for an aesthetic indoor plant nursery. Built with pure **HTML5** and **CSS3**, this project focuses on modern layout techniques, smooth navigation, and a cohesive nature-themed color palette.

This project was built as part of the **Oasis Infobyte Internship Program (OIBSIP)** under the **Web Development & Designing Track (Level 1 — Task 1)**.

---

## ✨ Features Checklist

- [x] **Animated Glassmorphic Title Card:** Dedicated 2-second intern identification overlay for demo video compliance.
- [x] **Sticky Navigation Header:** Quick smooth-scroll navigation across all page sections.
- [x] **Hero Section with CTA:** High-impact background, engaging typography, and an "Explore Collection" button.
- [x] **Why Choose Us Section:** 3-column card grid detailing key selling points (Sustainably Grown, Safe Shipping, Plant Care Support).
- [x] **Featured Products:** Interactive plant cards displaying pricing, images, and short descriptions.
- [x] **Footer:** Placeholder social media icons, contact details, and dynamic credits.
- [x] **Fully Responsive Design:** Optimized for Mobile, Tablet, and Desktop screen widths using CSS Flexbox and Media Queries.

---

## 🛠️ Tech Stack & Concepts Used

| Technology / Tool | Usage Details |
| :--- | :--- |
| **HTML5** | Semantic structure (`<header>`, `<section>`, `<footer>`, etc.) |
| **CSS3** | Custom Variables (`:root`), Flexbox, Animations, Glassmorphism Effects, Media Queries |
| **Google Fonts** | 'Poppins' font family for crisp, modern typography |
| **Unsplash** | High-quality plant visuals and background photography |
