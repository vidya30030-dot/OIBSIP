# 💻 Personal Portfolio Website

## 📌 Project Overview

A sleek, responsive personal portfolio website built using **HTML5** and **CSS3**. It serves as a digital résumé showcasing skills, background, featured internship projects, and contact info.

This project was developed for the **Oasis Infobyte Internship Program (OIBSIP)** under the **Web Development & Designing Track (Level 1 — Task 2)**.

---

## ✨ Features Checklist

- [x] **Video Title Card Overlay:** Dedicated 2-second intern identification screen for demo video verification.
- [x] **Hero / Profile Section:** Professional avatar, name, role title, and Call-To-Action button.
- [x] **About Me Section:** Overview of background, career interests, and internship goals.
- [x] **Skills Section:** Visual grid showcasing core frontend technical competencies with icons.
- [x] **Projects Section:** Responsive project cards linking directly to GitHub repositories.
- [x] **Contact Section:** Email and social links for professional networking.
- [x] **Smooth Scroll Navigation:** Seamless navigation header with sticky blur effect.
- [x] **Fully Responsive Layout:** Optimized across desktop, tablet, and mobile devices using CSS Grid & Flexbox.
